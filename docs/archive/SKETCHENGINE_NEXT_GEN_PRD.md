## Core Innovation: **Whiteboard Animation Engine**

### 1. 🖐️ The Drawing Hand
- Animated hand/pen that draws each element
- Feels like watching a friend explain
- Hand moves naturally between elements
- Pause at key moments for emphasis

### 2. 📐 Progressive Reveal (5 Beats)
```
Beat 1: "Let me show you..." → Draw main concept
Beat 2: "See how this connects..." → Draw relationship arrows
Beat 3: "In real life, think of..." → Draw Indian example
Beat 4: "The key insight is..." → Highlight with glow
Beat 5: "Now you get it! 💪" → Final flourish animation
```

### 3. 🎬 Animation Types
- **Stroke Draw**: Lines appear as if being drawn (SVG stroke-dasharray animation)
- **Fade Reveal**: Elements fade in at the right moment
- **Pulse Highlight**: Key concepts pulse/glow
- **Arrow Flow**: Arrows animate along their path
- **Typewriter Text**: Labels appear letter by letter
- **Bounce Entry**: Elements bounce in playfully

### 4. 🇮🇳 Indian Context Integration
- Cricket analogies (bowler = force, ball = object)
- Auto-rickshaw physics
- Chai/coffee chemistry
- Mango falling = gravity
- Diwali rocket = projectile motion
- Train journey = relative motion

### 5. ✨ Visual Style
- **Hand-drawn imperfect lines** (jitter effect)
- **Warm color palette** (saffron, peacock green, navy)
- **Sketch-style fills** (hatching, cross-hatching)
- **Playful icons** (emojis as accents)
- **Clean whiteboard background**

## Technical Architecture

### SVG Animation Pipeline
```
Question → Concept Extraction → Scene Composition → SVG Generation → Animation Orchestration → Render
```

### Key Components
1. **ConceptBreaker**: Decomposes concept into visual steps
2. **SceneComposer**: Arranges elements spatially
3. **StrokeGenerator**: Creates hand-drawn path data
4. **AnimationOrchestrator**: Sequences all animations
5. **MetaphorMapper**: Adds Indian context visuals

## Example: Explaining "Force = Mass × Acceleration"

### Beat 1: The Setup (0-2s)
```
[Hand draws a cricket ball]
Label appears: "Ball (mass = m)"
```

### Beat 2: The Action (2-4s)
```
[Hand draws bowler's arm with motion lines]
Arrow animates from arm to ball
Label: "Bowler applies FORCE"
```

### Beat 3: The Effect (4-6s)
```
[Ball moves with speed lines]
"a = F/m" appears with highlight
Label: "Ball ACCELERATES!"
```

### Beat 4: The Insight (6-8s)
```
[Split screen: heavy ball vs light ball]
Same force → different accelerations
Highlight pulse on "mass matters!"
```

### Beat 5: The Hook (8-10s)
```
[Formula F = ma appears with flourish]
Encouraging text: "Now you'll never forget! 🏏"
```
