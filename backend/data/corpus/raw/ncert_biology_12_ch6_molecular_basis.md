# Molecular Basis of Inheritance

## DNA Structure

**Watson-Crick Model (1953):**
- Double helix
- Two antiparallel strands (5' → 3' and 3' → 5')
- Sugar-phosphate backbone on outside
- Bases project inward
- Right-handed helix

**Base Pairing (Chargaff's Rules):**
- A = T (2 hydrogen bonds)
- G ≡ C (3 hydrogen bonds)
- A + G = T + C (purines = pyrimidines)

**Structural Features:**
- Pitch: 3.4 nm (10 bp per turn)
- Distance between base pairs: 0.34 nm
- Diameter: 2 nm

**Forms of DNA:**
- B-DNA: Watson-Crick model (most common)
- A-DNA: Dehydrated form, right-handed
- Z-DNA: Left-handed, zig-zag backbone

## DNA Replication

**Key Features:**
- Semi-conservative (Meselson-Stahl experiment)
- Bidirectional
- Continuous on leading strand, discontinuous on lagging strand

**Enzymes Involved:**

| Enzyme | Function |
|--------|----------|
| Helicase | Unwinds DNA double helix |
| Topoisomerase | Relieves tension ahead of replication fork |
| Primase | Synthesizes RNA primer |
| DNA Polymerase III | Main replication enzyme |
| DNA Polymerase I | Removes primers, fills gaps |
| DNA Ligase | Joins Okazaki fragments |

**Process:**
1. Origin recognition and unwinding
2. Primer synthesis
3. Elongation (5' → 3' direction only)
4. Leading strand: Continuous synthesis
5. Lagging strand: Okazaki fragments
6. Primer removal and gap filling
7. Ligation

## Transcription

**Definition:**
Synthesis of RNA from DNA template.

**Template Strand:** 3' → 5' (read direction)
**Coding Strand:** 5' → 3' (same sequence as mRNA, except U for T)

**RNA Polymerase:**
- Prokaryotes: Single enzyme for all RNA types
- Eukaryotes: RNA Pol I (rRNA), Pol II (mRNA), Pol III (tRNA)

**Steps:**
1. **Initiation:** Binding at promoter, formation of transcription bubble
2. **Elongation:** RNA synthesis 5' → 3'
3. **Termination:** Specific sequences signal end

**Post-Transcriptional Modifications (Eukaryotes):**
1. 5' cap: 7-methylguanosine
2. 3' poly-A tail: ~200 adenines
3. Splicing: Removal of introns

**Split Genes:**
- Exons: Coding sequences (expressed)
- Introns: Non-coding sequences (intervening)

## Genetic Code

**Properties:**
1. **Triplet:** 3 bases = 1 codon = 1 amino acid
2. **Degenerate:** Multiple codons for same amino acid
3. **Unambiguous:** Each codon = only one amino acid
4. **Universal:** Same in almost all organisms
5. **Non-overlapping:** Codons read sequentially
6. **Commaless:** No punctuation between codons

**Special Codons:**
- Start codon: AUG (also codes for Methionine)
- Stop codons: UAA, UAG, UGA (nonsense codons)

**Total codons:** 64 (4³)
- 61 code for amino acids
- 3 are stop codons

## Translation

**Definition:**
Synthesis of protein from mRNA template.

**Requirements:**
- mRNA (template)
- Ribosomes (machinery)
- tRNA (adaptor)
- Amino acids
- ATP, GTP

**Steps:**

**1. Initiation:**
- Small ribosomal subunit binds mRNA
- Start codon (AUG) recognized
- Initiator tRNA binds
- Large subunit joins

**2. Elongation:**
- Aminoacyl-tRNA enters A site
- Peptide bond formation
- Translocation

**3. Termination:**
- Stop codon in A site
- Release factors bind
- Polypeptide released
- Ribosome dissociates

## Regulation of Gene Expression

**Lac Operon (E. coli):**
- Inducible operon
- Structural genes: lacZ, lacY, lacA
- Regulatory elements: Promoter, Operator, Repressor gene

**Mechanism:**
- **Without lactose:** Repressor binds operator, blocks transcription
- **With lactose:** Lactose (inducer) binds repressor, releases it, transcription proceeds

## Human Genome Project (HGP)

**Goals:**
1. Identify all genes (~20,000-25,000)
2. Sequence 3.2 billion base pairs
3. Store information in databases
4. Develop analysis tools

**Key Findings:**
- Less than 2% codes for proteins
- Lots of repetitive sequences
- >99.9% similar between humans

## DNA Fingerprinting

**Basis:**
VNTRs (Variable Number Tandem Repeats) - unique to individuals

**Steps:**
1. DNA extraction
2. Restriction enzyme digestion
3. Gel electrophoresis
4. Southern blotting
5. Hybridization with probe
6. Autoradiography

**Applications:**
- Paternity testing
- Criminal investigation
- Evolutionary studies
