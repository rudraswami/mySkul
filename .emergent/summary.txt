<product_requirements>
The Dhruv AI project is an Indian B2C EdTech platform for competitive exams, featuring a personalized, Neuro-Symbolic AI mentor. Core functionalities include Personalized Learning Paths, Interactive Problem Solving, 24/7 Doubt Resolution, Advanced Performance Analytics, Realistic Mock Tests, and Stress Management.

The Mock Test Module generates AI-verified tests (Full-Length/Chapter-wise) with dual-layer AI, supporting Standard, Variant, and Adaptive modes, caching, database storage, and question deduplication. It requires retake options and post-test review features like Mentor feedback, Professor solutions, bookmarking, and flashcards.

The Auto-Note Mentor Module processes various inputs (audio/video, slides, PDFs, images) into verified, structured study packs. It includes real-time transcription, OCR, NLP for content chunking, Professor-layer verification, Mentor-layer summarization, and spaced-repetition.

A key addition requested by the user was a **Revenue Module** to monetize the platform via subscriptions using Stripe. This module required identifying features for subscription tiers and implementing a complete subscription management system.
</product_requirements>
