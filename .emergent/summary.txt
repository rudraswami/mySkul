**Auto-Note Mentor Module Requirements:** This module aims to transform any learning input (audio/video, slides, PDFs, images) into verified, structured, interactive study packs. Key features include real-time transcription (tuned for Indian accents), OCR, NLP for chunking/classifying content into Topic Cards, Professor-layer verification (fact-checking, syllabus tagging), Mentor-layer summarization/enrichment (flashcards, quizzes, diagrams), and spaced-repetition scheduling. Outputs are structured notes with interactive features (explain differently, flashcards, quizzes). Frontend needs Record Class button, live verified captions, progress bars, and a searchable note view. Backend should use a microservice architecture with asynchronous processing, queues, MongoDB for storage (note_id, student_id, transcript, concepts, flashcards, quizzes), caching for recent notes, and a vector store for retrieval. Privacy (explicit consent, encryption, role-based access) and performance (streaming transcription, background processing, scalability) are critical.
