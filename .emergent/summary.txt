<product_requirements>
The Dhruv AI project is an Indian B2C EdTech platform for competitive exams, featuring a personalized, Neuro-Symbolic AI mentor. Key functionalities include Personalized Learning Paths, Interactive Problem Solving, 24/7 Doubt Resolution, Advanced Performance Analytics, Realistic Mock Tests, and Stress Management.

Core modules:
1.  **Mock Test Module**: AI-verified tests (Full-Length/Chapter-wise) with dual-layer AI, supporting Standard, Variant, Adaptive modes, caching, database storage, question deduplication. Requires retake options, Mentor feedback, Professor solutions, bookmarking, and flashcards.
2.  **Auto-Note Mentor Module**: Processes various inputs (audio/video, slides, PDFs, images) into verified, structured study packs, including real-time transcription, OCR, NLP, Professor-layer verification, Mentor-layer summarization, and spaced-repetition.
3.  **Revenue Module**: Monetize via Stripe subscriptions, with defined tiers and full subscription management. This module has been successfully implemented.
4.  **AI Tutor Module**:
    *   **Core Modes**: Mentor, Professor, Both (Consensus summary).
    *   **Inputs**: Text, Voice, Image/PDF upload (for problem solving), Context Pin (connect lecture notes/tests). Phase A (Image/PDF Upload, Context Pin) is now complete.
    *   **Outputs**: Mentor Answer, Professor Answer, Consensus (summary, confidence, next actions), Action Buttons (Practice More, Add to Notes, Turn into Deck, Schedule Revision).
    *   **Personalization Features**: Track mastery by topic, dynamic difficulty adjustment, adaptive style (multi-language: English, Hinglish, Hindi, regional), student error fingerprinting. Phase B (Enhanced Personalization) is now largely complete.
    *   **Guardrails**: Retrieval from official syllabus, Math/Units Checker, Disagreement Alerts, Citation Chips.
    *   **Analytics & Feedback**: Performance stats, Parent/Teacher Dashboards, student feedback.
    *   **Wellness Layer**: Stress check-ins, smart nudges.
