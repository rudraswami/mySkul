## Known Issues

### Issue 1: Response Time
**Status:** ⚠️ User reported increased response time
**Root Cause:** Sequential execution (Professor → Mentor) takes ~30-45s
**Impact:** Better quality (Mentor reflects on Professor) vs. speed trade-off
**Potential Solutions:**
1. Reduce max_tokens from 1600 to 1200 (saves ~5-10s)
2. Parallel execution (loses reflection quality)
3. Add streaming to show partial results
4. Frontend loading states to manage user expectations

### Issue 2: LLM Tag Compliance
**Status:** ✅ Mitigated with intelligent fallback
**Root Cause:** LLM may not always follow tag structure consistently
**Solution:** Enhanced parseSections() with automatic paragraph splitting
